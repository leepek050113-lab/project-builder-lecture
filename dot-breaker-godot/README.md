# Dot Breaker (Godot 4.4)

Godot 에디터에서 `project.godot`를 열고 F5로 실행.
그래픽은 Pipstar(주사위 게임)의 팔레트·패널·칩 아이콘·폰트·사운드를 그대로 가져와 이 게임에 맞게 고침 (`CREDITS.md`).

## 게임 흐름
타이틀 → 라운드 → 보상 → 아이리스 아웃 → 상점 → 아이리스 → 다음 라운드 … 라운드 15를 깨면 승리(그 뒤 무한 모드 선택 가능), 목표를 못 넘기면 게임 오버.

## 라운드
- 필드: 2x2 픽셀 블록 168x168칸(약 2만 7천 개), 가운데에 28x28칸 빈 정사각형. 공도 2x2.
- 중력 없음: 공은 가운데에서 조준한 방향으로 날아가 블록과 벽에 반사됨.
- **튕김 = 공의 수명.** 블록이든 바깥 벽이든 한 번 칠 때마다 1 차감, 0이 되면 사라짐(마지막 3번은 깜빡임).
- 블록 체력: 바깥쪽일수록 단단하고, 랜덤 "광맥"은 2.5배. 라운드마다 `Data.hp_scale`로 오름. 체력이 남을수록 어둡게 보이고 맞을수록 밝아짐.
- 금광 블록(노란 점): 부수면 $1.
- 점수: 부순 블록 1칸 = 1점(업그레이드로 배율). 목표 `Data.target`.
- 조작: 마우스로 조준. 클릭 / SPACE = 다음 공 발사, 오른쪽 목록에서 공을 클릭하면 그 공을 발사, A = 남은 공 전체 발사(부채꼴), M = 음소거.
- 제한 시간 40초, **첫 공을 쏘는 순간부터** 흐름. 목표를 넘기면 그 즉시 클리어(남은 공은 사라짐).
- 실패: 시간이 다 되거나, 공을 다 쏘고 모두 사라졌는데 목표 미달.
- 보상: 클리어 $3 + 라운드/2, 남은 시간 5초당 $1, 안 쓴 공마다 $1, 이자 $5당 $1(최대 $5), 라운드 중 금광·행운으로 번 돈.

## 상점 (6칸, 2줄 x 3칸)
- 위 3칸 업그레이드, 아래 3칸 공. 클릭으로 구매. 리롤 $2부터 리롤할 때마다 +$1.
- 등급 Common / Rare / Epic / Legendary (카드 테두리·태그 색). 라운드가 오를수록, 행운의 부적이 있을수록 높은 등급이 자주 나옴 (`Data.rarity_weights`).
- **전용 업그레이드**: 특정 공 전용(카드에 "전용: 폭탄" 태그, 아이콘이 그 공 색). 가지고 있는 공의 전용 업그레이드만 나옴. 세 번째 칸은 65% 확률로 전용.
- 공 보관 8칸(배낭으로 +2). 보유 공 우클릭 = 반값 판매(최소 1개는 남김).

## 콘텐츠
- 공 18종 (`data.gd`의 `BALLS`): 기본공·쇳덩이·날쌘공·쌍둥이·행운공(C) / 드릴·폭탄·분열공·스파크·유령공(R) / 레이저·집속탄·흡혈공·프리즘(E) / 공허·노바·혜성·미다스(L).
- 업그레이드 100개 (`UPGRADES`): 일반 50 + 공 전용 50(공마다 2~3개). 효과는 전부 `stats` 딕셔너리에 더해지는 숫자이고, `field.gd`의 `st()` / `bs()`와 `main.gd`가 읽음.

## 구조
- `scripts/field.gd`: 블록 그리드(PackedFloat32Array) + 이미지 한 장에 그림(블록마다 노드 없음). 공은 0.45칸 단위로 쪼개 움직여서 빠른 공도 2px 블록을 건너뛰지 않음. 모든 공 효과(폭발, 레이저, 번개, 분열, 복제…).
- `scripts/main.gd`: 라운드 진행, HUD, 보상 창, 상점, 아이리스 전환. 타이머는 물리 틱에서 돌아서 프레임이 끊겨도 공보다 먼저 흐르지 않음.
- `scripts/data.gd`: 팔레트, 공, 업그레이드, 목표·체력 곡선, 상점 확률.
- `scripts/icons.gd`: 16x16 아이콘을 코드로 그림(Pipstar의 칩 아이콘 + 공 구체).
- `scripts/ui.gd`: 픽셀 패널/버튼/라벨. 숫자는 ThaleahFat, 한글은 Mona12(12px).
- `shaders/iris.gdshader`: 2px 격자에 맞춘 아이리스 와이프.
